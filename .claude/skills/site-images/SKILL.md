# Site images

Static images for arndvs.com are generated by code so they stay consistent. The rules are
in `rules/site-images.md`. Read that file before making or changing an image.

## Where things are

- `rules/site-images.md` — palette, fonts, sizes, and layout rules.
- `python/site_images/style.py` — the color tokens, font loaders, and drawing helpers.
- `python/site_images/generate_cards.py` — share cards and blog heroes.
- `python/site_images/generate_placeholders.py` — wireframe placeholders.
- `python/site_images/crop_screenshot.py` — crops a browser capture to 2:1.
- `visuals/arndvs-site-images/` — the generated images.

## Steps

1. Decide which kind of image is needed: share card, blog hero, screenshot, or
   placeholder. The rules file says when each applies.
2. Confirm whose palette applies. The site's own images use the site palette. A
   placeholder for another product's screen uses that product's palette. A treatment
   made for a post about another brand stays with that post.
3. Add the image to the right generator:
   - Share card: add an entry to `SHARE_CARDS`. Every number on it must be in the site's
     facts ledger (`docs/reference/facts-ledger.md` in the site repo).
   - Blog hero: add a `hero_<slug>()` function built on `hero_base()` and register it in
     `BLOG_HEROES` under the post's slug.
   - Placeholder: add a builder and register it in `PLACEHOLDERS`.
4. Use the tokens and helpers in `style.py`. Do not hard-code a color or load a font
   that is not in `python/site_images/fonts`.
5. Run the generator and look at the result at full size. Check that no text overflows
   its column or runs under the panel.
6. Copy the result into the site repo with `--site PATH`, and wire it into the page
   there. Blog heroes also need `pnpm seed:post-heroes` in the site repo.

## Commands

```bash
pip install pillow
python python/site_images/generate_cards.py --site ../arndvs
python python/site_images/generate_placeholders.py --site ../arndvs
python python/site_images/crop_screenshot.py capture.jpg out.jpg
```
