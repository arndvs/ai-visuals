# arndvs.com Site Images

The static images used on arndvs.com: link-preview share cards, blog post heroes, and
wireframe placeholders, all generated by code so they stay in one style.

## What it holds

- `share/` — eight 1200×630 share cards: the default card and one per project page.
- `blog-heroes/` — four 2400×1350 heroes for the posts that had no image.
- `placeholders/` — three 1518×759 wireframes that stand in for MCRDSE screens that
  can't be captured yet.
- `experiments/` and `share/experiments-*.jpg` — each experiment's 2400×1350 card image
  (illustration only, since the card sets its own title) and 1200×630 share card. These
  are stills of an animated visual, not Pillow drawings: the RAG Cost Estimator's come
  from [`rag-cost-levers`](../rag-cost-levers) at its payoff step.

## How it was made

- **Engine:** Python with Pillow. No browser and no image model; every shape and line of
  text is drawn by `python/site_images/`.
- **Agent:** Claude wrote the generators from the site's dark-theme tokens.
- **Rules:** [`rules/site-images.md`](../../rules/site-images.md).
- **Fonts:** Outfit and DM Sans, the faces the site loads, bundled under the SIL Open
  Font License.

## Usage

Regenerate everything, and copy it into a checkout of the site repo:

```bash
pip install pillow
python python/site_images/generate_cards.py --site ../arndvs
python python/site_images/generate_placeholders.py --site ../arndvs
```

Blog heroes go live on the site when `pnpm seed:post-heroes` is run in the site repo.
